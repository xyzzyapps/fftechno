# video - basement

The song-specific visual settings read by `python -m fftechno girl|video`.
Everything else has a default in the look, so the tables are optional.

The source is the first video in `ascii/` (or set `source:` explicitly); the crop
window and look are below.
crop_start: 2.0
crop_duration: 3.0
look: outline
loop_beats: 4

## Parameters

Per-look overrides.

| look    | key        | value |
|---------|------------|-------|
| outline | top_margin | 70    |
