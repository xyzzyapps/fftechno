# fftechno - sampler definitions

The first **sample-based** song. It has no `## Instruments` table: every stem is a
`## Samplers` row that reads a file from `samples/` (fetched by
`python -m fftechno samples`). The graphs are generated by `fftechno/sampler.py`.

The beat is a boom-bap trip-hop pattern at 88 BPM: the TR-909 SP kit (a 909 recorded
through an SP-1200) over the Amen break, slowed with `rate=0.81` so it fits two bars
and sits behind the drums.

`pat` is a 16-step pattern inside one bar, repeated on every bar. `hits` are absolute
16th steps from the song start (used for the break, which fires every two bars).
`vel` is a parallel velocity list. `trim` is how long each copy plays; `rate` is a
varispeed factor (below 1 is slower and lower); `tempo` would change speed at constant
pitch; `gain` is a per-instrument gain.

| name  | sample                             | params |
|-------|------------------------------------|--------|
| kick  | samples/triphop_kit/kick.wav       | pat=0\|6\|10, gain=1.0, trim=0.6 |
| snare | samples/triphop_kit/snare.wav      | pat=4\|12, gain=0.85, trim=0.5 |
| clap  | samples/triphop_kit/clap.wav      | pat=12, gain=0.55, trim=0.4 |
| hat   | samples/triphop_kit/hat-closed.wav | pat=0\|2\|4\|6\|8\|10\|12\|14, vel=0.9\|0.55\|0.9\|0.55\|0.9\|0.55\|0.9\|0.55, gain=0.5, trim=0.2 |
| ohat  | samples/triphop_kit/hat-open.wav   | pat=6\|14, gain=0.32, trim=0.6 |
| brk   | samples/breaks/amen.wav            | hits=0\|32\|64\|96, rate=0.81, gain=0.75, trim=5.4545 |
