# fftechno - song arrangement

TB-303 pattern study with a tribal drum feel: **130 BPM, 96 bars = 2:57**.
A single acid pattern over kick, clap, hats and a bouncy sub bass. No toms, no congas,
no crash.

The 303 pattern is "Acid Tabs 200" from acid-tabs.com, a square-wave 16-step
pattern in a minor scale. Pattern by J.McConaghy / Acid-Tabs.com, licensed
CC BY-SA. The notes, accents, slides and rests are reproduced exactly; the three
acid stems differ only in squelch/filter voicing, not in the pattern itself.

Form: kick intro -> hats -> acid_a -> clap + sub -> acid_b -> break -> acid_c ->
peak -> break -> final -> fade.

bpm: 130
bars: 96
fade_bars: 6
sidechain_key: kick
low_bus: acid_a|acid_b|acid_c
reverb_seconds: 1.6
